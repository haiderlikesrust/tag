How it works

From post to position in seconds.

  1. 01

    Add Hypertag to Chrome

    Open x.com. Every $cashtag listed on Hyperliquid now shows a live price with Long and Short buttons.

    Connect with one signature

Security

Built so it can't touch your funds.

  • Trading-only key

    Hypertag uses a Hyperliquid API wallet. It can open and close positions. Hyperliquid itself blocks it from withdrawing or transferring anything.

  • Your key never touches x.com

    The key is created and stored inside the extension, and every order is signed there. The X page never sees it.

  • Revoke anytime

    Disconnect in one click, or remove the key from your Hyperliquid account settings whenever you like.

  • Verified signing

    Order signing is tested byte-for-byte against Hyperliquid's official SDK.

FAQ

Questions, answered.

Is Hypertag made by X or Hyperliquid?

No. Hypertag is an independent tool. It works on x.com and talks to Hyperliquid's public API, but it isn't affiliated with or endorsed by either.

Can Hypertag move or withdraw my money?

No. It only holds a Hyperliquid API wallet, which can place and close orders but can't withdraw or transfer. That limit is enforced by Hyperliquid, not just by Hypertag.

Is it open source?

Yes. The full extension source is on GitHub under the MIT license, including the order-signing code and its tests against Hyperliquid's official SDK.

What does it cost?

Nothing. Hypertag adds no fees of its own. You pay Hyperliquid's normal trading fees, exactly as you would on their site.

Which wallets can I connect?

Any browser EVM wallet, including MetaMask, Rabby, Coinbase Wallet, OKX Wallet and Phantom. You can also paste an API wallet key you created on Hyperliquid instead.

Which markets can I trade?

All of Hyperliquid's main perpetual markets. Spot and builder-deployed markets aren't supported yet.

Can I try it without real money?

Yes. Switch to Testnet in the extension popup and use Hyperliquid's testnet funds.

Which browsers does it work in?

Chrome and other Chromium browsers such as Brave, Arc and Edge, on desktop.

  1. 01

    Download

    Get hypertag-x.y.z.zip from the latest release and unzip it into a folder you'll keep.

  2. 02

    Open extensions

    Paste chrome://extensions into the address bar and turn on Developer mode (top right).

  3. 03

    Load unpacked

    Click Load unpacked and choose the unzipped folder, the one that contains manifest.json.

  4. 04

    Refresh X

    Reload x.com. Long and Short appear under every $cashtag. Click Connect in the sidebar card to link Hyperliquid.

The Chrome Web Store listing is in review. To update a manual install, download the new release, replace the folder and click ↻ on Hypertag in chrome://extensions.
